Windows 10 / 11 64비트 공식 포터블 버전 설치 매뉴얼

Windows x64 Portable
1 공식 릴리스 접속 및 Windows 버전 다운로드

웹 브라우저를 열고 아래 공식 릴리스 페이지 링크에 접속합니다:

🔗 공식 최신 릴리스 페이지: https://github.com/gochujangs33-dot/Craft-Studio/releases/latest
⚡ 최신 버전 즉시 자동 다운로드: https://github.com/gochujangs33-dot/Craft-Studio/releases/latest/download/ArtCraftStudio-portable-x64.zip

페이지 하단 Assets 목록에서 3번째 파일인 ArtCraftStudio-portable-x64.zip 파일을 클릭하여 다운로드합니다. (클릭 시 브라우저에서 자동 다운로드 시작)

💡 다운로드 안내: ArtCraftStudio-portable-x64.zip (약 1.49 GB) 파일은 런처뿐만 아니라 PhotoCraft, SolidCraft 등 17종의 모든 제작 프로그램이 사전 완비된 풀 패키지입니다. 추가 설치 없이 즉시 오프라인에서도 작동합니다.
2 다운로드 폴더에서 압축 해제하기

브라우저 다운로드가 완료되면 내 PC의 다운로드 폴더로 이동합니다.
다운받은 ArtCraftStudio-portable-x64.zip 압축 파일을 마우스 우클릭한 후 [압축 풀기(T)...]를 선택하여 원하는 위치에 압축을 풉니다.

실행 방법 및 Windows SmartScreen 예외 처리 안내

Step 3 & 4
3 압축 해제된 폴더에서 ArtCraftStudio 실행

압축이 풀린 ArtCraftStudio-portable-x64 폴더 안으로 들어갑니다.
폴더 최상단에 위치한 파란색 나비/화살표 아이콘의 ArtCraftStudio (또는 ArtCraftStudio.exe) 응용 프로그램을 더블클릭하여 실행합니다.

💡 런처가 실행되면 좌측 사이드바와 카드 목록에서 17종의 모든 프로그램을 원클릭으로 바로 실행하거나 최신 버전으로 관리할 수 있습니다.
4 Windows SmartScreen 팝업이 뜰 경우 대처 방법

오픈소스 독립 배포 소프트웨어 특성상 최초 실행 시 Windows Defender SmartScreen의 "Windows의 PC 보호" 파란색 경고 알림 창이 나타날 수 있습니다. 이는 디지털 인증서가 없는 신규 배포 파일에 대해 Windows가 띄우는 정상적인 보안 확인 창입니다.

🛡️ SmartScreen 통과 2단계

알림 창이 나타나면 아래 순서대로 클릭하여 간단히 실행할 수 있습니다:

  • 1 알림 창 본문에 있는 밑줄 친 추가 정보 텍스트를 클릭합니다.
  • 2 화면 우측 하단에 새롭게 나타나는 실행 버튼을 클릭합니다.
